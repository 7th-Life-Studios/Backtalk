bundles on 2026-09-18. Generated, not hand-written. `UNSTATED` means the
package declares no license in its metadata and needs to be checked by hand
against its own repository before any claim is made about it.

"Ships in" is which half of the install the package lands in: `app` is
`Program Files\Backtalk\Backtalk`, `engine` is `Program Files\Backtalk\engine`.
